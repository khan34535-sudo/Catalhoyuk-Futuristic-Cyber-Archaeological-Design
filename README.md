# Futuristic-Cyber-Archaeological-Design 🏛️🌐

An experimental 3D WebGL archaeological information system mapping the 9,000-year-old Neolithic settlement of Çatalhöyük. Built with Three.js and custom spatial raycasting, this platform bridges digital humanities and immersive web applications.

> **⚠️ Prototype Notice:** This project is a functional design prototype intended for data visualization and digital humanities exploration. Details within the prototype may not be 100% historically or archaeologically exact; the primary purpose is to digitize information and conceptualize spatial layout. All artifact geometries and placements are placeholders and can be replaced with actual high-fidelity 3D models or scanned assets as needed.

## ✨ Key Features
- **3D Spatial Stratigraphy:** Interactive multi-building volumetric visualization with dynamic timelines spanning 7100–5700 BCE.
- **Micro-Stratigraphic Data Matrix:** Deep-dive modal inspection panes covering bioarchaeology, lithics, pyrotechnology, and architectural phasing.
- **Dual Audience Toggle:** Instantly switch between granular, peer-reviewed **Academic** citations and accessible **Public** summaries.
- **WebGL Raycasting & HUD:** Real-time camera-projected UI labels, particle atmospheres, and custom glowing wireframe architectural shaders.
